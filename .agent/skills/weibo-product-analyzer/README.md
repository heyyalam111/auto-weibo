# 微博热搜产品创意分析器

一个基于Claude Code的技能(Skill),用于自动分析微博热搜榜单并生成产品创意报告。

## 功能特性

✨ **自动化分析流程**
- 自动抓取微博热搜榜单(最多20条)
- 使用AI搜索每个热点的背景信息
- 智能评分系统:有趣度(80%) + 有用度(20%)
- 自动提取产品创意(名称、核心功能、目标用户)

📊 **精美HTML报告**
- 响应式设计,支持移动端和桌面端
- 深色主题,现代化UI设计
- 评分可视化(进度条 + 颜色编码)
- 优秀项目(≥80分)金色高亮
- 良好项目(60-79分)蓝色标注
- 事件脉络时间线展示
- 产品创意卡片布局

🚀 **静默执行**
- 一次性完成所有分析,无需中途确认
- 自动错误处理和重试机制
- 分析完成后自动打开浏览器展示报告

## 使用方法

在Claude Code中输入以下任一命令即可触发技能:

```
分析微博热搜
```

```
微博热搜产品创意
```

```
分析今天的微博热点
```

技能会自动:
1. 获取当前微博热搜榜单
2. 搜索每个热点的背景信息
3. AI分析并评分
4. 提取产品创意
5. 生成HTML报告
6. 自动打开浏览器展示

报告会保存在 `reports/` 目录下,文件名格式:
```

```

报告包含:
- 📊 分析概览(总数、优秀/良好项目数、平均分)
- 🏆 高分热点排行(≥60分)
- 📱 详细分析列表(所有热搜话题)
  - 热搜标题 + 排名
  - 综合评分(可视化进度条)
  - 背景信息
  - 事件脉络时间线
  - 产品创意详情

## 评分标准

### 有趣度 (80分满分)
- **话题性** (30分): 是否引发广泛讨论
- **新奇性** (25分): 是否具有新颖独特的角度
- **传播度** (25分): 是否容易传播和分享

### 有用度 (20分满分)
- **实用性** (10分): 是否解决实际问题
- **市场需求** (10分): 是否存在明确的用户需求

### 总分计算
```
总分 = 有趣度 × 0.8 + 有用度 × 0.2
```

### 评级标准
- **优秀**: ≥80分 (金色高亮)
- **良好**: 60-79分 (蓝色标注)
- **一般**: <60分 (灰色)

## 配置说明

默认配置位于 `SKILL.md` 中,可以根据需要调整:

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 分析热搜数量上限 | 20条 | 最多分析的热搜话题数量 |
| 最少热搜要求 | 5条 | 少于此数量会停止分析 |
| API超时时间 | 10秒 | API调用超时时间 |
| API重试次数 | 3次 | 失败后的重试次数 |
| 报告保存目录 | `reports/` | HTML报告保存位置 |

## 常见问题

### Q: 技能没有触发怎么办?
A: 确保使用触发关键词,如"分析微博热搜"。如果仍未触发,检查 `skills/` 目录是否在Claude Code可访问的位置。

### Q: API调用失败怎么办?
A: 技能会自动重试3次。如果仍然失败,请检查网络连接。

### Q: 可以分析历史热搜吗?
A: 当前版本仅支持分析当前实时热搜榜单。

### Q: 可以自定义评分标准吗?
A: 可以修改 `SKILL.md` 中的评分标准和权重。

### Q: 报告可以导出为PDF吗?
A: 可以在浏览器中使用"打印"功能保存为PDF。
