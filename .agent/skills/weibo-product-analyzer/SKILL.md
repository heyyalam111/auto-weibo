# 微博热搜产品创意分析器 (Weibo Hot Search Product Analyzer)

## ⚠️ 静默执行协议 (Silent Execution Protocol)

> **核心原则：一口气完成任务，禁止中途打断**

**你必须遵守以下规则：**

1. **Do not ask for confirmation to proceed.** (不要请求确认以继续)
2. **Generate the full output in one go.** (一次性生成完整输出)
3. **If data is missing, use the defined defaults.** (如果数据缺失，使用默认值)
4. **Never ask "是否继续？" or "需要我继续吗？"** (绝不询问是否继续)
5. **Never say "如果您需要..." or "请告诉我..."** (绝不请求额外信息)

### 唯一允许暂停的场景

| 场景 | 动作 |
|------|------|
| API调用失败(3次重试后) | 输出："微博热搜API调用失败，请检查网络连接或稍后重试。" 然后停止 |
| 热搜数量少于5条 | 输出："获取的热搜数量不足(仅X条)，数据量不足以分析。" 然后停止 |
| Web搜索服务不可用 | 使用热搜标题作为背景信息继续分析 |

---

## 概述

本技能用于分析微博热搜榜单，从产品创意的角度评估每个热点，生成精美的产品创意分析报告。

### 触发条件
- 用户消息包含："分析微博热搜"、"微博热搜产品创意"、"微博热点分析"、"微博热搜榜单"
- 用户请求分析当前热门话题并提取产品创意

### 不触发条件
- 抖音、小红书等其他社交平台
- 不涉及产品创意的纯新闻分析
- 历史热搜数据分析(仅分析当前热搜)

## 执行流程

### Step 1: 获取微博热搜榜单

使用天行数据API获取当前热搜榜单：

```python
import requests
import json

# 天行数据微博热搜API
api_url = "https://apis.tianapi.com/weibohot/index"
api_key = "76f000a3377212e17c8f5d716761f2f4"

try:
    response = requests.get(api_url, params={"key": api_key}, timeout=10)
    data = response.json()
    
    if data.get("code") == 200:
        hot_searches = data.get("result", {}).get("newslist", [])
        # hot_searches 包含热搜列表
    else:
        print(f"API错误: {data.get('msg')}")
except Exception as e:
    # 静默重试3次
    pass
```

**API返回数据结构**：
```json
{
  "code": 200,
  "msg": "success",
  "result": {
    "newslist": [
      {
        "hotword": "热搜标题",
        "hotwordnum": "热度数值",
        "hottag": "标签(热/新/爆)"
      }
    ]
  }
}
```

**数据提取**：
- 热搜标题: `hotword`
- 热度值: `hotwordnum`
- 标签: `hottag` (热/新/爆/空)

**自动处理**：
- API超时 → 自动重试3次，每次间隔5秒
- 返回数据格式异常 → 尝试备用API或使用模拟数据
- 热搜数量 < 5条 → 停止执行并提示用户

```
IF 热搜数量 < 5:
    → 输出："获取的热搜数量不足(仅X条)，数据量不足以分析。"
    → 停止执行
ELSE:
    → 静默继续 Step 2
```

### Step 2: 搜索热点背景信息

对每个热搜话题使用 `search_web` 工具搜索背景信息：

```python
# 对每个热搜话题
for topic in hot_searches[:20]:  # 限制最多分析20个
    # 使用search_web工具
    query = f"{topic['title']} 新闻 背景"
    background_info = search_web(query)
    
    # 提取关键信息
    # - 事件起因
    # - 事件发展
    # - 相关人物/机构
    # - 社会影响
```

**搜索策略**：
- 每个话题搜索关键词：`{热搜标题} + 新闻 + 背景`
- 提取前3-5条相关新闻
- 汇总成事件脉络

**错误处理**：
- Web搜索失败 → 使用热搜标题作为背景信息，继续分析
- 搜索结果为空 → 标注"背景信息不足"，继续分析

### Step 3: AI分析热点并评分

对每个热点进行AI分析，评分标准：

**有趣度 (80分满分)**：
- **话题性** (30分)：是否引发广泛讨论
- **新奇性** (25分)：是否具有新颖独特的角度
- **传播度** (25分)：是否容易传播和分享

**有用度 (20分满分)**：
- **实用性** (10分)：是否解决实际问题
- **市场需求** (10分)：是否存在明确的用户需求

**总分计算**：
```
总分 = 有趣度 × 0.8 + 有用度 × 0.2
```

### Step 4: 提取产品创意

基于热点分析，提取1-3个产品创意，每个创意包含：

1. **产品名称**：简洁有力，体现核心价值
2. **核心功能**：3-5个关键功能点
3. **目标用户**：明确的用户画像描述

**创意提取原则**：
- 紧密结合热点话题
- 解决用户痛点
- 具有可行性
- 创新但不脱离实际

**示例**：
```
热搜话题：AI绘画工具爆火
产品创意：
  名称：AI头像生成器
  核心功能：
    - 一键生成多风格个人头像
    - 支持职业照、卡通、艺术风格
    - 批量导出高清图片
  目标用户：需要更新社交媒体头像的年轻用户(18-35岁)
```

```json
          "target_users": "目标用户描述"
        }
      ]
    }
  ]
}
```

### Step 6: 生成HTML报告

使用模板生成精美的HTML报告，包含以下内容：

```html
<!-- 报告结构 -->
📊 分析概览
   - 分析日期

   - 平均评分

   - 优秀项目 (≥80分) - 金色高亮

   对每个热搜话题：
   - 热搜标题 + 排名

   - 事件脉络时间线
   - 产品创意卡片
```

**文件命名规则**：
- 格式：`微博热搜分析_{YYMMDD}_{HHMM}.html`
- 示例：`微博热搜分析_260210_1220.html` (2026年2月10日 12:20)
- 保存位置：`F:\CC SKILLLS\微博热搜提取\reports\`

**HTML样式要求**：
- 现代简洁设计
- 深色主题(推荐)或浅色主题
- 响应式布局(支持移动端)
- 使用渐变、卡片、适当动画
- 中文字体优先：微软雅黑、苹方、思源黑体
- 评分可视化：
  * ≥80分：金色渐变背景 + "优秀"徽章
  * 60-79分：蓝色渐变背景 + "良好"徽章
  * <60分：灰色背景

## 错误处理（静默策略）

### 自动静默处理（不中断）

| 错误 | 处理方式 |
|------|----------|
| API超时 | 静默重试3次，每次间隔5秒 |
| 单个话题搜索失败 | 使用标题作为背景，继续处理其他 |
| Web搜索服务不可用 | 跳过背景信息搜索，直接分析 |
| 数据格式异常 | 尝试备用解析方式 |
| 热搜标题过长 | 自动截断为前50字符 |
| 产品创意生成失败 | 标注"暂无创意"，继续其他话题 |
| HTML生成警告 | 忽略警告，继续生成 |

### 需要停止并提示用户

| 错误 | 处理方式 |
|------|----------|
| API调用失败(3次重试后) | 提示网络问题，请稍后重试 |
| 热搜数量 < 5条 | 提示数据不足，无法分析 |
| 文件保存失败 | 提示磁盘空间或权限问题 |
| 浏览器打开失败 | 提示手动打开报告文件 |

## 报告模板说明

HTML报告模板位于：`templates/report_template.html`

模板使用占位符，在生成时替换为实际数据：
- `{{ANALYSIS_DATE}}` - 分析日期
- `{{TOTAL_TOPICS}}` - 热搜总数
- `{{TOPICS_DATA}}` - 话题分析数据(JSON)

模板特性：
- 响应式设计(Bootstrap 5或自定义CSS Grid)
- 深色主题(可选浅色主题)
- 评分可视化(进度条 + 颜色编码)
- 时间线组件(事件脉络展示)
- 卡片布局(产品创意展示)
- 平滑动画(滚动触发)
